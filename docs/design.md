# Nudgelo design specification

The current design uses pale neutral surfaces, blue #2757e7 actions, navy text, peach and lavender puzzle surfaces, and Manrope typography. The desktop app uses a horizontal navigation bar; phones use a compact header and bottom navigation.

The Home page begins with one actual interactive model. Four length changes synchronize its pendulums; calculations and motion use the same equations. The mission library, quick-start steps, free-lab entry, explicit pending Twitch hosting state and FAQ follow. No audience totals, streaks or social proof are fabricated.

Mobbin references actually inspected for this revision: [Headspace discovery](https://mobbin.com/screens/9fb74046-d5b5-4af9-9204-78cacdd67661), [Headspace activity path](https://mobbin.com/screens/1cba404f-413c-4a8b-be36-d791e9ca4fed), [Duolingo activity](https://mobbin.com/screens/7bb8916e-d373-43c3-9614-70afaf9abfed). Their discovery hierarchy, illustrated activity grouping and focused actions informed this original implementation. No protected screenshots, characters or assets are shipped.

The original blue/coral SVG instruments show physical depth while preserving the actual mathematical motion. Pendulum A/B labels have opaque white backings. Primary actions, control keys, selected mission and completion state are distinct without relying only on color. Solo mode omits idle vote counts and chat commands from the control dock; chat rehearsal, live mode and Stage view expose those commands.

Focus rings remain on interactive controls. Content-route focus does not draw a black outline around the entire page. Reduced motion leaves a readable model state and removes decorative transitions. Browser-size testing is not evidence of physical iOS or VoiceOver/NVDA operation.

The source retains the earlier implementation and review history in Git. Existing final-media work remains on hold: no new Devpost thumbnail, 15-image gallery or demonstration video is produced in this revision. Repository captures are actual engineering QA renders.
